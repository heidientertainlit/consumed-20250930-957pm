---
name: Rank creation boundaries
description: Public Play ranks are community activities, distinct from protected profiles and fixed tracking lists.
---

Keep ranked-list creation in Play separate from custom personal tracking-list creation. Public ranks may accept community contributions; private ranks must not accept another user's items merely because that user owns the inserted item.

**Why:** The user explicitly requested restoring rank creation while preserving the fixed tracking-list model and existing security protections. They approved tightening private-rank insertion while retaining owner access and public contributions. Applying an owner-only rule to every rank would remove intended public participation; treating public ranks as full profile access would weaken a different boundary.

**How to apply:** When changing rank authorization, verify both private-rank denial and continued public contributions. Do not reopen protected user/profile reads or resurrect custom tracking lists to support Play ranks.
