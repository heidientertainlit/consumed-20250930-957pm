Missing/invalid identity is 401; a valid non-admin is 403. Service-role internal calls remain supported. Twenty exact live reporting-RPC overloads now deny PUBLIC/anon/authenticated and retain service_role execution; no direct frontend/native RPC caller was found for these functions.
Production proof: both endpoints now reject public-anon requests with HTTP 401; sampled direct RPC calls return permission denied. Live ACL inspection verifies all 20 signatures, and active downloaded source matches the intended deployment. Unit tests cover administrator/non-administrator authorization paths. A real signed-in administrator response test was not performed; normal response construction is preserved and reviewed.
Unrelated pre-existing limitation: the partnerships branch references missing get_platform_affinity_insights. It was not created or redesigned in this remediation.
