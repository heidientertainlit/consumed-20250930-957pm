Check whether your browser can read viewing history again without another login.

No connection to Consumed

No passwords or cookies are collected. History stays in this extension on this computer. Nothing is sent to a server.

Before you check

  1. Sign into Netflix directly in this browser.
  2. Select your own profile and open Viewing activity from your Netflix account.
  3. Confirm the selected profile. Only already-loaded rows will be read.

Use the same label each time. It does not verify which Netflix profile is active.

Install this extension in desktop Chrome or Edge to begin.
